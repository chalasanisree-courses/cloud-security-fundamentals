1 The system — app & infrastructure

This is the application ring of the layered model — the software, plus the AWS infrastructure it runs on. Take a photo-viewer app. The golden rule: only the load balancer faces the internet; everything else hides in private subnets. Click a piece to see its job:

2 How a request flows — and where it’s attacked

Walk Mary’s request from her browser into the app. At every stop a different attack becomes possible — and a different AWS service stops it. Step through:

Identity shows up twice on this path
At the login stop, Cognito proves who you are (authentication) and issues a token the load balancer checks. At the app stop, the application decides what you may touch (authorization) — it runs SELECT * FROM photos WHERE owner='Mary', so Mary sees only her own. The IdP knows who; the app knows what.

3 How data flows — and how it’s stolen or secured

The whole point of the app is the data — Mary’s photos. It has to move safely (in motion) and sit safely (at rest) — and the uploads themselves can be weaponized.

In motion · at rest

Keep S3 traffic off the internet
The app’s hop to S3 can use a VPC endpoint, so that traffic stays on the private AWS network and never crosses the public internet — even though S3 lives outside your VPC.
When the upload itself is the attack
A user can upload a malicious file to S3 instead of a photo. Amazon GuardDuty (Malware Protection for S3) scans new objects and flags infected ones — you then act on the flag (it detects, it doesn’t auto-delete).
Remember

Three views of one app. System: a 3-tier app, segmented — only the load balancer is public, everything else private. Request flow: each stop has an attack and a defense — MITM → TLS, DDoS → Shield, stolen password → Cognito + MFA, origin-bypass → allow only CloudFront in the load balancer’s Security Group, SQL injection → WAF, vulnerable libraries → Inspector — and identity splits into who (Cognito) vs what you own (the app). Data flow: protect it in motion (TLS + a VPC endpoint to S3) and at rest (encryption / KMS), and scan uploads for malware (GuardDuty).
